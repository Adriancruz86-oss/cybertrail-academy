# CyberTrail Academy

## Overview
CyberTrail Academy is a story-driven cybersecurity learning game designed to help players understand and apply cybersecurity concepts in a visual and interactive environment. The game focuses on preparing players for the CompTIA Security+ certification through engaging missions and real-world scenarios.

## Project Structure
The project is organized into several directories and files, each serving a specific purpose:

- **public/**: Contains static assets such as icons, audio files, and the web app manifest.
- **src/**: Contains the main application code, including game logic, user interface components, and data management.
- **tests/**: Contains unit tests for various components of the application.
- **docs/**: Contains documentation files, including the game design document and technical plans.
- **index.html**: The main HTML file that serves as the entry point for the web application.
- **package.json**: Configuration file for npm, listing dependencies and scripts.
- **tsconfig.json**: TypeScript configuration file.
- **vite.config.ts**: Configuration file for Vite, the build tool used in this project.
- **README.md**: This documentation file.

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm (Node package manager)

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd cybertrail-academy
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application
To start the development server, run:
```
npm run dev
```
This will launch the application in your default web browser.

### Building for Production
To build the application for production, run:
```
npm run build
```
The built files will be located in the `dist` directory.
